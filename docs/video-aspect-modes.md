# 画面比例扩展规格

## 目标

在保留现有画面模式和历史数据兼容性的前提下，新增：

- `21:9`
- `自适应`：使用当前播放区域的实际宽高比
- `自定义`：用户输入宽、高，比例全局保存

四个播放核心应呈现一致结果；MPV 需要同步其原生长宽比属性，不能只调整外层 `PlayerView`。

## 模式编号

现有编号不得改变：

| ID | 模式 |
|---:|---|
| 0 | 原始 |
| 1 | 16:9 |
| 2 | 4:3 |
| 3 | 填充 |
| 4 | 裁剪 |
| 5 | 21:9 |
| 6 | 自适应 |
| 7 | 自定义 |

影片历史只保存模式 ID；自定义宽高使用全局偏好保存，默认值为 `21:9`。

## 行为

- 原始：完整显示并保持片源比例。
- 16:9、4:3、21:9、自定义：把视频显示比例覆盖为目标比例。
- 自适应：目标比例取当前播放容器比例；布局或方向变化后重新计算。
- 填充：完整铺满播放区域，允许变形，不裁剪。
- 裁剪：保持片源比例并放大裁剪。
- PiP 对固定、自适应和自定义比例应用对应比例，并沿用现有合法范围限制。
- 播放核心重建、Surface 重建和视频尺寸更新后应恢复当前模式。

## UI

- 播放页、控制面板和播放器设置页统一使用单选弹出层，不再逐项循环或平铺八个按钮。
- 显示顺序为：`原始`、`16:9`、`4:3`、`21:9`、`填充`、`裁剪`、`自适应`、`自定义`；仅调整显示顺序，不改变持久化 ID。
- 点击 `自定义` 后打开宽、高输入框；输入不合法时不关闭对话框。
- TV 端默认聚焦当前模式，自定义输入框支持左右切换宽高、向下进入取消/确定、向上返回输入框。

## 测试策略

- 单元测试画面模式编号、映射、比例解析和兜底。
- 源码/资源测试确保手机、电视和直播控制面板均包含三个新模式。
- 源码测试确保 MPV 同步 `keepaspect` 和 `video-aspect-override`。
- 运行：
  - `.\gradlew.bat :app:testMobileArm64_v8aDebugUnitTest`
  - `.\gradlew.bat :app:testLeanbackArm64_v8aDebugUnitTest`
  - `.\gradlew.bat :app:assembleMobileArm64_v8aDebug`
  - `.\gradlew.bat :app:assembleLeanbackArm64_v8aDebug`

## 边界

- 不修改现有 0～4 的持久化含义。
- 不增加 Room 字段或数据库迁移。
- 不修改第三方 Media3 AAR；新增模式在应用层映射。
- 不引入新依赖。
