# 原生增强模式 TMDB 未匹配选集按钮优化设计

**日期：** 2026-08-19  
**状态：** 已确认，待实施

## 目标

优化 Android 原生增强模式在整季没有有效 TMDB 分集匹配时的选集展示：整季从增强卡片退化为影视原生模式风格的选集按钮网格，尽可能完整地展示源站集数、标题和文件大小，同时保留现有的播放交互、焦点导航和选中态。

## 背景与现状

当前增强选集由 TmdbEpisodeAdapter 使用 `adapter_tmdb_episode.xml` 卡片布局渲染。卡片适合有 TMDB 海报、日期、评分和简介的场景；当整季没有有效 TMDB 分集时，卡片会失去主要视觉内容，导致选集按钮占用空间大、信息密度低，并且长源站名称容易被单行截断。

影视原生模式已经有成熟的选集按钮样式和交互，包括按钮背景、选中态、遥控器焦点态以及文件大小标签。本次设计复用这些视觉约定，但不直接切换详情页的整个 Adapter，以避免破坏当前增强模式的集数映射、长按菜单和跨端行为。

## 展示规则

1. 仅在以下条件全部满足时启用原生按钮网格回退：
   - 当前处于原生增强模式；
   - 当前选集容器使用网格模式；
   - 当前整季没有任何通过 TmdbEpisodeMatcher.shouldApply(...) 校验的有效 TMDB 分集。
2. 只要整季存在一个有效 TMDB 分集匹配，整季继续使用增强卡片，不混合卡片和按钮两种样式。
3. 非原生增强模式不改变现有行为。
4. 原生增强模式的列表模式不改变现有行为；回退只针对截图对应的选集网格场景。
5. TMDB 误匹配、集号不一致或被匹配策略拒绝的条目均视为无效匹配。

## UI 设计

### 原生按钮

- 使用影视原生模式一致的按钮背景、圆角、边框、点击反馈和焦点反馈。
- 继续使用当前网格列数配置，支持 2 列和 3 列。
- 按钮最小高度保持原生模式密度；长标题允许最多两行，并根据内容适度增加高度，避免无意义的大卡片空白。
- 集数和源站名称优先展示清理后的完整文本；没有可清理标题时回退到源站原始名称。
- 文件大小作为独立小标签显示，不覆盖集数文本。
- 选中项继续使用当前播放高亮颜色；遥控器焦点继续使用现有放大、描边和阴影效果。

### 不显示的内容

整季无有效 TMDB 匹配时不显示 TMDB 专属信息：海报、TMDB 日期、评分、简介以及共享回退海报，避免出现空卡片或误导性信息。

## 实现边界

- 在 TmdbEpisodeAdapter 内增加“原生按钮网格回退”的显示状态或等价策略。
- 使用独立的原生回退 item 布局，避免继续让增强卡片布局承载隐藏的海报层和简介层。
- 保留 TmdbEpisodeAdapter 的 Episode 数据源、TMDB 集数映射、选中项、点击、长按、键盘和焦点监听。
- 回退判断抽成无 Android 依赖的策略方法，便于单元测试。
- 不修改 TMDB 请求、匹配算法、播放 URL 或详情页数据加载逻辑。

## 数据流

1. setItems(...) 接收当前季源站选集、TMDB 分集映射和源站集号映射。
2. 以实际展示集号调用 TmdbEpisodeMatcher.shouldApply(...)，统计是否存在有效匹配。
3. 当模式、原生增强标记或数据变化时，更新适配器的回退状态并刷新布局。
4. 回退状态下，ViewHolder 绑定源站选集文本和文件大小；普通增强状态继续走现有 TMDB 卡片绑定逻辑。
5. 点击和长按仍回调同一个 Listener，不会改变播放和菜单行为。

## 测试策略

### 策略单元测试

覆盖：

- 原生增强 + 网格 + 0 个有效匹配 => 启用回退；
- 原生增强 + 网格 + 至少 1 个有效匹配 => 不启用回退；
- 非原生增强 => 不启用回退；
- 列表模式 => 不启用网格回退；
- 被匹配策略拒绝的 TMDB 条目不计入有效匹配。

### Adapter/UI 绑定测试

覆盖：

- 回退按钮显示源站集数和清理后的源站标题；
- 文件大小标签显示且不覆盖标题；
- 2 列和 3 列模式都能创建正确的网格参数；
- 有效匹配存在时仍绑定增强卡片；
- 选中、焦点、点击和长按监听不回归。

### 模拟器验证

使用 emulator-5556：

- 安装最新 debug APK；
- 进入原生增强模式；
- 验证整季 TMDB 未匹配时为紧凑按钮网格；
- 分别验证 2 列、3 列、长标题、文件大小和当前选中项；
- 验证存在部分有效匹配时整季仍保持增强卡片；
- 使用遥控器方向键和点击操作验证焦点与播放行为。

## 验收标准

- 整季无有效 TMDB 匹配时，不再出现大面积空白增强卡片。
- 选集按钮风格与影视原生模式一致，且 2 列/3 列均可读。
- 长源站名称、集数和文件大小在不遮挡的前提下尽可能完整显示。
- 存在任意有效 TMDB 匹配时，原有增强卡片视觉不变。
- 既有测试通过，debug 构建成功，并在 emulator-5556 上完成实际验证。
