## 2. 已发现问题与实际处理

| 问题 | 处理与边界 |
| --- | --- |
| 默认 zh 丢设备字形、影响自动匹配关闭用户 | zh 补设备字形；明确简繁偏好保持；Exo 自动关闭仍按 Locale 选轨 |
| 目标轨尚未出现就报失败并清登记 | 缺轨等待后续回调或期限；下发前 arm；仅真实选中成功回执，期限到按真实状态判定 |
| 空标签/唯一候选/已选轨被误认成外挂目标 | 仅可信非空目标 label 与 MIME 匹配可选；不凭数量、语言或 selected 推断身份 |
| 旧自动请求盖掉手动选择、切集与释放残留 | 手动 setSub 与字幕 setTrack 取消登记；自动内部使用不取消自己的通道；新 item/clear/release 清理；音轨切换不中断字幕 |
| provider 未识别语言被抹空 | 只在归一化结果有效时替换，未知语言保留原元数据 |
| 起播未知时长被固化、跨媒体缓存污染 | 主线程缓存实际时长，真实引擎值优先；新 item/clear/release 清零；请求惰性补取，查询后排序前再次刷新，复制保留全部 identity；未知/直播不阻塞 |
| 前缀不同作品、英文词片段、续集误选 | 标题词边界及版本元信息判据；先身份过滤再取最优，错误高分不挡有效候选；纯符号归一化空值过滤 |
| 季集冲突只扣分、releaseInfo 标记漏检 | 自动选择硬拒绝明确冲突；检查名称、releaseInfo 及所有显式 SxxExx，手动列表不删候选 |
| 测试名/断言失真、定时夹具绕过初始化 | 名称与断言一致，具体候选断言，真实方法状态测试；假 timer 保存同一真实 runnable，验证到期/取消；不声称裸 player 夹具覆盖完整引擎重启 |
| 恢复锚点过时 | 两份原字幕任务文档的当前状态与下一步已同步，保留历史实施记录 |
